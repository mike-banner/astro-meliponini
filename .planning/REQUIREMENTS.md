# Melipone Astro - Requirements

## Product Requirements
1. **Catalog Display**: Show honey and candle products fetched from WP.
2. **Cart Management**: Add, update, remove items using CoCart v2 API.
3. **Luxury UI**: Premium visual aesthetics (typography, colors).

## Technical Requirements
- Handle CoCart authentication keys via Nanostores.
- Support VPN connectivity for the WP backend.

## Acceptance Criteria
- User can add a product to the cart and see the total update.
