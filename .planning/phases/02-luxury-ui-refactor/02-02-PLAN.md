<design_system>
Same system as Plan 01. Reuse, do not reinvent:
- `hsl(var(--accent-gold))` (#d4af37 honey gold) for accents, `--accent-gold-light` for tint backgrounds.
- `--letter-spacing-premium: 0.22em;`
- Sharp corners: `--radius: 0px`. The luxury system does NOT use `rounded-2xl` / `rounded-full`.
  Buttons are the only exception (global rule forces `border-radius: 5%`).
- Font is "abchannel" sans. The luxury system does NOT use `font-serif` anywhere.
- h1/h2/h3 already get `font-weight:400; letter-spacing:0.05em; text-transform:uppercase` from global.css.
- Established micro-copy register: "Découvrir nos élixirs", "Explorer l'univers" (French, evocative).

Off-brand markers to ELIMINATE on these pages: `font-serif`, `rounded-2xl`, `rounded-3xl`,
`rounded-full`, `text-amber-600`, `bg-amber-50`, `text-gray-500/900` as the primary text color.
Replace grays with the design tokens: `text-foreground`, `text-muted-foreground`,
`border-border`, `hsl(var(--accent-gold))`.
</design_system>
