<design_system>
The luxury language is ALREADY DEFINED. Do not invent new tokens or fonts. Reuse:

CSS variables (src/styles/global.css):
- `--accent-gold: 43 74% 50%;`   → use as `hsl(var(--accent-gold))` (the #d4af37 honey gold)
- `--accent-gold-light: 43 74% 90%;`
- `--letter-spacing-premium: 0.22em;`
- `--radius: 0px;` (sharp corners — the buttons override to 5% via global rule, leave that alone)

Global typographic rules already applied to h1/h2/h3 in global.css:
  font-weight: 400; letter-spacing: 0.05em; text-transform: uppercase;
Body font is "abchannel" (the Chanel-style corporate face). Do NOT switch any element to
`font-serif` — that is the OLD off-brand look being removed elsewhere.

Reference heading scale from index.astro (replicate the feel, not a copy-paste):
  font-size: clamp(1.2rem, 4.5vw, 2.5rem); font-weight: 400; letter-spacing: 0.12em; text-transform: uppercase;

Scroll animation utility (global.css):
  `.fade-up` (starts opacity:0 translateY(30px)) → `.fade-up.visible` reveals.
  The IntersectionObserver that adds `.visible` currently lives inline in index.astro's <script>.
  Product listing pages need their own copy of that observer script (see Task 3).

Luxury micro-copy already established on the home page: "Découvrir nos élixirs",
"Explorer l'univers". Match this register (French, evocative, honey/rarity themed).
</design_system>
